## How to use this template

This is a testable buyer hypothesis, not an invented persona. Do not add a fictional name, photograph, biography, preferences, quotations, or demographic details merely to make the profile feel complete.

For every external factual statement:

1. Add one or more evidence IDs in brackets, such as `[E-004; E-009]`.
2. Mark an unsupported proposition `[HYPOTHESIS]`.
3. State when a conclusion is an inference.
4. Preserve contradictory or unresolved evidence.
